# TFCB 2026 Demo

This repository contains my tools for comp bio Fall26 coursework, including an experiment log, an image, and the Lecture 3 tidy qPCR data exercise.

- Creator: Dunham Clark (GitHub: @dunclark)
- `experiments/`: experiment logs written in Markdown.
- `experiments/img/`: images referenced in the experiment logs.
- `analysis/qpcr/`: qPCR exercises and related data.
- Each qPCR exercise folder contains a README, a `data/` folder for input-data documentation, and a `tables/` folder for the tidy CSV.

## Repository layout

```text
tfcb_2026_demo/
├── README.md
├── experiments/
│   ├── FULL_LOG_FILENAME.md
│   └── img/
│       └── ExpandedTissue.png
└── analysis/
    └── qpcr/
        └── 2026-10-15_i2_tidy_data_exercise/
            ├── README.md
            ├── data/
            │   └── README.md
            └── tables/
                └── tidy_data.csv
